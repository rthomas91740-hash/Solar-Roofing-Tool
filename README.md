# Fleet Wolf Roofing and Solar

Geotab add-in for roofing and solar crews: job photos captured in Geotab Drive, viewed and printed in MyGeotab.

Separate product from Fleet Wolf Job Photos (own SolutionId, own menu names, own function names).

- `index.html` - Drive capture add-in
- `gallery.html` - MyGeotab records/gallery add-in
- `configuration.json` - add-in configuration to paste into MyGeotab
